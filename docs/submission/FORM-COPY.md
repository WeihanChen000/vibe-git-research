## 作品名称

Vibe-Git Research：跨 Agent 的科研协议、评审与证据交接

## 方向

主要方向：AI Agent。验证场景：AI + Biology。是否同时勾选 Biology 由队长按作品定位决定。

## 项目简介 / 科研问题 / 使用场景

科研协作中的困难不只是让多个 Agent 同时工作：成员可能使用不同平台，数据版本、方法参数和验收口径会在交接时漂移，执行完成也不代表结果已经独立复核。

Vibe-Git Research 面向小型科研团队，在原 Vibe-Git 的人员拓扑、成员提案、队长对齐和发布流程上，增加统一 Agent 适配接口、冻结科研协议、文件指纹与输入回执、独立评审、返工版本和获批文件交接。队友绑定自己的执行端，沿用原界面的待办入口完成领取、执行、提交与评审；账号密钥保留在成员本机。Codex 与 SciencePAL 已接入同一个项目，其他五种本地 Agent 接口已整合但未逐一实跑。

真实验证以公开 1CRN 蛋白结构为案例。SciencePAL 官方 Biology Agent 实际使用 Python 与 Biopython 计算溶剂可及表面积；Codex 用独立 NumPy 实现复核。1000/5000 点结果的相对差异为 0.1114%，低于预先约定的 2%。流程经历预设方法细化退回，以及实际发现的批准凭证缺失退回，修复后完成双向文件交接与再评审。源码、结果、参数、版本和评审证据均可追溯。

平台不限于 1CRN，研究问题、材料与验收要求由用户定义。当前验证为一个 SciencePAL 账号与本机 Codex，尚不代表真实双账号联调。SciencePAL 的价值是可调用的科研专家与工具环境，不宣称其算法不可替代。项目贡献是让跨平台科研协作拥有共同协议和可核对的验收链，而非证明模型天然更准确。
