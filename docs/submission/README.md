## 唯一主案例与计数

修复后的真实项目 `85455c15-1857-4c5f-a876-85ca8b6cf7fa`：SciencePAL 计算 1 次、上游 Codex 评审 2 次、报告执行 2 次、报告评审 3 次、对齐 2 次、变更评审 1 次，共 11 次作业。31 份原始附件、34 条输入回执。补证保留原成果，R2 只改报告并复用原计算和批准；评审本身仍有调用与独立核算成本。

结果为 2967.6165 Å²，对比独立参考 2973.1627706139175 Å²，相对差约 0.1865%，预设容差 2%。单一固定结构的几何复现，不是生物学发现。四项检查不包含逐残基全面独立参考。

原单机验收的 23/29、早期整合的 12/20 是**不同历史包**，没有合并成最新统计。先前误配置尝试另有计算；“一次上游计算”不覆盖全部开发历史。
