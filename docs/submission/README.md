## 当前有意留空

用户要求暂不填写队伍名、队长姓名/邮箱、其他成员实名信息和逐人分工。技术说明与视频不主动写入这些身份信息。公开 GitHub 链接和 Git 历史本身可识别作者，因此这不是严格的全链路双盲匿名包。

已只读核对问卷第一页：需匹配报名的队伍名、队长姓名、邮箱，其他成员信息、作品名、领域、项目简介；简介建议 1500 字符。团队总人数 1–3 人。问卷提示身份材料用于管理，作品材料尽可能匿名。没有填入虚构身份去绕过必填校验，**后续页面的上传格式、大小限制、声明勾选及最终字段尚未逐项核验**。

1. 队长填写与报名一致的行政信息，并核实资源声明中的实际个人分工。

3. 按后续页面实际要求上传、确认声明、最终提交，保存成功页/回执。只上传或填写部分内容不算提交完成。
