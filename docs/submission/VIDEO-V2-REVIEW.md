## 本次改变

- 用公开 1CRN 的“哪些部位暴露在水中”作为故事；不从功能清单和术语开始。
- 开场人物为一位队长、两位成员。A 用 SciencePAL 计算，B 用 Codex 分析，队长负责对齐、发布与评审。
- 使用隔离的三成员真实应用界面录制建项、上传、冻结约束、发布、退回、返工和交接。演练输出明确带 synthetic，不使用真实账号或伪装多人实测。
- 修正演练生成器缺少文件引用及读错返工反馈位置的问题；正式生产校验未放宽。最终演练为 COMPLETED、2/2 通过，计算两轮、分析一轮；开发中的失败与最终展示分开，不宣称连续实时录屏。
- 独立的真实科学结果来自原已公开实验；批准依据缺失也是已有真实发现，不将情境示例冒充真实成员行为。
- 英文配音 Aria，逐句中文字幕；具体操作和状态有局部放大，原应用控件和逻辑未改变。
- 在线页提供原生播放器、章节跳转、可选英文字幕、下载和证据链接；无需评委访问 GitHub 文件页。

## 语音工具复用
