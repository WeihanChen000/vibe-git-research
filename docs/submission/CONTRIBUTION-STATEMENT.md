## 可直接用于提交的正文

本项目是在原 Vibe-Git 基础上完成的科研协作扩展。贡献分为原版基础、队友提供的多 Agent 执行层，以及本人主导的科研功能与整合验证三部分。

**原版基础。** 原 Vibe-Git 已有成员身份与邀请、队长和成员权限、提案版本与冻结、对齐和裁决、任务发布、Git 协作、软件任务生命周期及需求变更与防偏移机制。人员拓扑、甘特图、顶部操作栏和详情抽屉也来自原版。本项目沿用这些基础与交互方式，保留原作者归属，不将其列为本人新增原创。

**队友提供的代码。** 队友提供了多 Agent 改造方案与代码，包括统一 AgentAdapter 接口、AgentRegistry 注册表、AgentExecutor 执行器，以及 Codex、Claude、Cursor、Gemini、OpenCode、DeepSeek 六种本地适配器和 Relay 入口改造。这部分提供了按平台选择执行器的架构与初始实现。后续进行了整合、重构和兼容修正，仍明确保留队友贡献，不将其表述为本人独立设计或全部从零编写。

**本人主导的新增工作。** 本人负责将产品方向推进到 Codex × SciencePAL 的科研成果交接，并在原版与队友代码基础上，使用 Codex 辅助完成：SciencePAL 云端执行接入、成员平台绑定与原线程接续；冻结科研输入、成果格式、方法参数及文件回执；独立评审、退回、补证复审和批准后的下游交接；科研侧原文覆盖、返工范围约束、增量变更与未受影响成果复用。同时推进错误恢复、运行预算、首次使用提示和获批成果展示，组织真实联调、证据核验与参赛材料整理。相关科研治理沿用原版的协作思想，并针对科研文件与评审证据扩展，不将通用的多人协作或防偏移概念主张为个人原创。

**核心贡献与验证。** 本人的核心贡献是把不同 Agent 的执行能力接入同一套科研协议，让成果连同版本、检查与批准依据进入下一步，并支持保留原成果的恢复和复用。修复后的 1CRN 案例已完成两轮真实流程：SciencePAL 执行计算，Codex 独立复核；补充原执行证据后获批，随后仅修改报告并沿用原计算及批准记录。该项目保留 31 份原始附件、34 条输入回执；11 次 Agent 作业中包含失败评审重试。上游计算未因补证或报告变更而重新执行，不代表没有评审成本或所有历史尝试都只计算过一次。

**AI 辅助与外部资源。** 本人负责需求方向、方案选择、迭代要求与验证目标，Codex 辅助代码实现、测试、证据核验和材料整理，不声明全部代码由本人手工编写。SciencePAL 服务、Codex 工具、1CRN 结构数据、SASA 方法及 Biopython、NumPy 等属于外部资源，保留各自来源与归属。当前真实主路径为 Codex × SciencePAL；其他本地适配器不等于全部平台均已真实验证。案例由一位操作者在一台电脑上使用现有 Codex 登录和一个 SciencePAL 账号完成，保留人工介入与失败记录，不宣称无人值守、多人跨电脑验收、科学新发现或已证明总体节省时间与费用。

## 表单字数较少时使用的简版

本项目基于原 Vibe-Git，沿用其成员权限、提案与任务流程、变更治理以及拓扑/甘特界面。队友提供统一 Agent 接口、注册表、执行器和六种本地平台适配器，后续整合与重构保留其贡献归属。本人主导科研场景扩展，使用 Codex 辅助实现 SciencePAL 接入、冻结输入与成果约束、独立评审、补证恢复、批准依据随文件交接及报告变更后的成果复用，并推进真实验证和产品体验完善。核心贡献是让跨 Agent 科研成果可核查地交接和恢复。Codex × SciencePAL 两轮真实案例已有 31 份附件、34 条回执支持；验证范围为单操作者、单机，不宣称全部平台实跑、科学新发现或整体效率提升。原版、队友代码、AI 辅助及第三方数据与工具均分别注明来源。
