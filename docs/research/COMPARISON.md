# 与原版及手工交接的对照

基线为原仓库 `TFboy1/vibe-git` 的 `f3e888f`，本仓库保留这一 Git 提交。它不是附件中另一个 `b9bbe3b` 基线，也不代表原项目将来全部版本。

## 能力对照

| 维度 | 原版基础 | 当前科研扩展 | 证据与限制 |
|---|---|---|---|
| 多人协作 | 已有成员、提案、队长权限 | 沿用身份，绑定各自平台 Agent | 不把多人协作算新发明 |
| 平台 | 面向 Codex 开发 | Codex 与 SciencePAL 同项目 | 另五种本地适配接口已整合，但未逐一实跑 |
| 交付 | Git、代码任务、已有接口契约 | 冻结数据、产物 schema、文件 SHA256 回执 | 格式正确不等于科学正确 |
| 评审 | 原有任务完成与协作协议 | 独立成员评审、退回、保留尝试版本、下游放行门禁 | 文字批准仍可能判断错误 |
| 等待输入 | 原开发工作流 | SciencePAL 原线程问答后接续 | 真实回放有受控测试 |
| 界面 | 拓扑、甘特、提案、详情 | 保留原操作位置，加入交接边、待办责任人、科研证据 | 不宣称每个像素一致 |
| 通用性 | 软件开发协作 | 自定义科研问题、输入与验收；案例可选 | 当前输入文件大小、格式受限 |
| 演示 | 原仓库产品演示 | 真实科研产物逐阶段回放 | 回放不是现场运行 |
| 多账号 | 多人成员体系 | 本人连接器、独立 Key 与权限隔离 | 真人双账号闭环仍待队友完成 |

## 同一输入的受控对照

[运行前协议](../../vibe-git/SCIENCEPAL-COMPARISON-PROTOCOL.md) · [完整报告](../../vibe-git/SCIENCEPAL-CRN-COMPARISON.md) · [原始 JSON](evidence/handoff-comparison.json)

固定同一 1CRN 输入与产物，三组分别调用原版普通任务 doneTask 方法、完整手工检查表、科研版实际 envelope / schema / review 函数。手工表由 Codex 代做，**不是真人用户实验**。原版方法运行在隔离桩环境，不是原版完整 UI 的端到端试验；既有接口 CONTRACT 门禁不属于这个普通任务探针。

| 样本 | 原版普通任务完成方法 | 完整手工表（Codex 代做） | 科研版门禁与给定评审 |
|---|---|---|---|
| 正确产物 | 完成 | 接受 | 接受 |
| 旧协议、错回执、缺代码、参数偏离、缺评审、评审退回（六类） | 完成 | 拒绝 | 拒绝 |
| 数值偏移且文字评审误同意 | 完成 | 拒绝 | 接受 |

原版“完成”仅代表普通任务生命周期条件成立，不能推断原作者或真实用户会认可错误研究。科研版的实际提升是把六类核查变为必经门禁；没有测量真人耗时、点击数或自然错误率。认真复算的手工表发现了全部七类错误，因此不能声称自动系统更准确。

## 复现

在 `vibe-git` 目录，安装 Python 与 NumPy 后：

```powershell
python fixtures/expert-case/reference.py fixtures/expert-case/1CRN.pdb data/crn-comparison/independent-reference.json
npm ci
npm run build
node apps/host/scripts/compare-crn-handoffs.mjs
```

使用 Git 克隆版以保留 `f3e888f` 对照；GitHub Download ZIP 无 Git 历史，不能直接运行原版方法探针。先创建输出目录 `data/crn-comparison`（若不存在）。本次保存结果在本目录 evidence；重跑结果在本地 data，不入库。
