这次只回答：**面对同一份真实科研成果，哪条路径更容易确认“当前能不能用、依据在哪里、下一步找谁”？**

使用已完成的 1CRN 实验原文件，不重跑模型，不需要队友、Key 或安装软件。不是新实验、自动执行测速或科学准确率比赛。材料包准备工作由助手完成，两边都复用；首次配置成本仍未测。

## 先准备

1. 下载完整 ZIP 并解压；把 `RECORD.md` 另存到你自己的位置，用记事本填，或把其中四行复制到聊天填写。**别把填好的私人记录直接推到公开仓库。**
2. 准备一个秒表。在桌面建一个空目录 `交接对照输出`，下面建 `01-手工`、`01-拓扑`、`02-手工`、`02-拓扑` 四个空目录。
3. 先读完共同检查表，不预读材料或答案。抛硬币决定材料 01 先走哪条路径；材料 02 反过来。第二次接触同一材料会更熟悉，要如实记录，不能据此算普遍效率。

每轮都回答相同问题：**在该快照时点，sasa.json 能交给下游吗？依据是什么？接下来轮到谁、做什么？** 若能交接，将源文件、当前成果、绑定它的批准记录这三个原文件复制进本轮输出目录；若不能，目录保持空，在记录中写出缺什么。不要为了凑通过而改任何原文件。

## 怎么记，才公平

只计自己实际找、读、判断、复制的秒数。离开电脑、等页面加载时暂停秒表，把等待另记。先看说明、下载及解压属于共同准备，不摊到某一条路径。已安装工具和已配置系统写“复用既有配置”，不能记为首次成本为零。

“补查次数”指为了补清一个不明确事实，额外打开文件/面板或返回核对一次；正常按检查表第一次查阅不算。每复制/下载一个文件记 1 次，批量复制三个也记 3。卡住三分钟可停止并写“未完成”，不要用猜测补齐。协助、误点和返回修改也记下来。

全部四轮完成后才打开 `AFTER-CHECK.md`。这轮若拓扑仅让状态更清楚，而没有少复制文件，就照实写；只读回放本来不会代你执行交接。**目前不测完整配置、真正自动派发/传输、跨账号或网络恢复，也不推导节省百分比。**

如果这一步都不省心，先指出最烦的一处；如果确有帮助，再决定是否值得做包含真实配置的完整操作对照，不再扩功能。
