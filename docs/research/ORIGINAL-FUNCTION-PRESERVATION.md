## 本轮修复

1. **独立安装包遗漏依赖**：原发布 `files` 不带 Relay，新 Host 顶层导入却需要它及 Ajv，源码 workspace 会掩盖这一问题。修复根运行依赖，打包本仓库编译后的 Protocol 与 Relay，避免依赖同名远端包中不存在的科研协议。没有发布到 npm。
2. **软件入口可发现性**：科研项目存在时根入口可能进入科研页面，本轮在原“本地工作区”弹层加“打开原版软件协作”，指向 `/?view=software`。科研本机代理没有软件 API，不在其上放无效跳转；显示回到原房间及登录要求。原布局/CSS不变。
3. **保留要求落盘**：新增仓库 `AGENTS.md` 与兼容回归命令，后续不能把新增门禁当成原功能的替代品。

## 后续优先级与贡献表述

先守住上述原功能，再继续验证科研的遗漏需求、擅改方法、评审加要求。当前仍不能说“偏移完全解决”；尤其自然语言需求覆盖和评审自行扩大范围，不能用字段检查通过来替代。

报告应分别写清：

- **原 Vibe-Git 团队贡献**：共同意图管理、版本化提案、冻结/裁决/发布、变更影响分析、证据失效及原界面。这是项目治理基础，不能归为本次科研扩展原创。
- **同学提供的适配器贡献**：把绑定 Codex 的执行抽象成 AgentAdapter / Registry / Executor，为跨平台复用协作协议提供共同接口；同时如实写出主 CLI 还未切换的边界。
- **后续科研扩展贡献**：SciencePAL 专业执行接入、冻结科研成果与批准依据、科学检查及补证/交接等。它们补充原防偏移流程，不取代其主线。

以上按代码来源分层，不替成员编造个人署名；同学在原防偏移机制中的具体个人贡献应依据原提交/本人确认署名，不能只按后来合入代码的提交者归属。
