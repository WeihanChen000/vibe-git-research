# 首次使用复核与改进

2026-10-30。范围是队友拿到源码包后的首次准备、加入、绑定、提案、协作执行与返工。继续使用原顶部入口、成员卡片、算力网弹层、右侧待办和甘特，没有新增另一套向导页面。

## 已发现并处理

| 问题 | 原来的影响 | 本轮修复与证据 |
| --- | --- | --- |
| 不同提案入口行为不一致 | 刷新后从房间工具栏打开会显示空编辑器；成员卡片的提交快捷入口未直达编辑 | 浏览器先复现失败，再统一入口加载；成员卡片继续沿用原 open(plan) 行为 |
| 切换入口丢草稿、后台更新可能覆盖编辑基础 | 顶部按钮重置草稿，保存使用轮询中的最新修订号，可能覆盖别处的修改 | 当前页面内保留草稿；记录编辑开始时的修订号，检测并发更新，保留文字并禁止静默覆盖；明确放弃后才载入保存版本 |
| 接入成功后不知道下一步 | 验证 Key、绑定之后没有引导到提案；提案提交后只看到空白拓扑 | 在原弹层提供提交提案入口；房间显示本人尚缺什么、是否已准备好、正在等队长还是队友 |
| 连接器管理入口不够直接 | 待办优先让成员复制 work 命令，容易另开一个 worker | 本人待办直接回到原算力网；已绑定账号设置折叠，执行器按钮保持可见；等待输入时提示回 SciencePAL 原线程回答 |
| 异常输入提示不清楚 | 非 URL 邀请显示通用解析错误；空 Agent 目录没有可操作解释 | 中文邀请纠错提示；无效 Key 不保存；空目录明确说明账号可访问但无可用专家，禁止空绑定，可修改后继续 |
| 建项前视角和卡片不准确 | 切到甘特仍显示成员拓扑；无任务时出现 0/0；缩放图标被按钮内边距挤小 | 未建项的甘特说明何时有任务；只在科研准备卡片隐藏无意义进度；恢复正常大小缩放控件 |
| 首次启动仍要手工找浏览器入口 | 双击后只有终端链接 | 启动脚本尝试打开默认浏览器，另保留独立的一次性备用链接；说明当前安装/构建阶段，支持只准备和重新构建 |

## 验证结果

- 将源码接入 ZIP 解压到新的临时目录，确认没有 node_modules 与 dist。通过实际 open-research.cmd --prepare 安装 348 个依赖并完整构建，当次 npm audit 报告 0 vulnerabilities。
- 从该独立安装目录启动编译后的本机入口：页面成功返回，身份与 Key 均未配置，连接器停止；一次性票据再次使用被拒绝。测试没有读入真实账号或项目凭据。
- 26 项隔离浏览器检查通过：包含错误输入修复、提案各入口和草稿并发保护、双人项目冻结、权限下的发布、连接器启停与心跳、评审退回、返工、恢复、复评通过、文件交接、甘特与 390px 布局；未捕获浏览器异常。
- 133 项科研回归通过，包含真实 Node 连接器子进程的安全停止、释放日志锁和再次启动。全工作区类型检查、构建与 git diff --check 通过。
- 复核脚本为 apps/web/scripts/verify-research-first-use.mjs，配合 apps/host/scripts/preview-research-onboarding.mjs。本机证据保存在 data/onboarding-demo/first-use-report.json、kit-install.json 以及对应截图，私人 data 目录不进入接入包。

## 证据边界与后续

这里是工程代理按新队友路径做的操作检查，不是真人可用性研究。模拟保留真实成员权限、连接器与协作状态机，但模型结果为确定性合成数据，不是新的科研发现，也不能证明 SciencePAL 专业质量或两个账号已联通。

真实队友仍需核验跨电脑 HTTPS 可达性、本人专家权限，以及在 SciencePAL 原线程回答后能否按实际账号接回。UNKNOWN 启动结果继续要求核对原任务，不能为减少点击而自动重发。Codex 继续由本人终端处理本地任务包，页面会给出成员身份配置步骤，不冒充已启动模型。

下一次最有价值的验证是让队友只拿接入包与 FIRST-RUN 操作，记录实际停顿点；目前没有必要再增加新的首页、向导或第二套管理面板。
