# Iris：两次退回怎样形成科研协作闭环

这是 2026-10-30 已完成的真实实验回放：当前 Codex 和 SciencePAL 原生 Biology Agent 共享冻结的 UCI Iris 数据，交叉执行与评审。只读，不需要账号、不调用模型，也不会重新发布任务。

## 先看什么

按顶部“回放阶段”顺序查看九个阶段，也可以自动播放。点击节点、评审线或交接线，仍在原来的右侧抽屉查看依据。顶部案例选择可切到 1CRN，查看另一场真实实验中的等待输入和原线程接续。

1. **数值错误退回**：首版候选把 5.1 写成 6.1，提前披露为受控测试。Biology 实际用 Python 逐行检查后退回；原始 CSV 未变。
2. **返工与交接**：Codex 修复，Biology 复审通过。仅在下游结果的真实输入回执匹配获批文件后，才标“文件已交接”。
3. **代码缺失退回**：Biology 的统计值正确，但只交付脚本名。Codex 按冻结要求退回；这是实际发生的交付缺陷，不是预设错误。
4. **补齐后完成**：Biology 重新运行并交付代码与版本；Codex 独立复算及语义复核通过，2 / 2 项完成。两种平台都做过作者和评审者。

## 科学结果与边界

150 条历史记录，三个物种各 50 条，单位 cm。花瓣长度均值为 setosa 1.462、versicolor 4.260、virginica 5.552；后两组范围 3.0–5.1 与 4.5–6.9 有重叠。描述性统计不能证明完美分类或因果关系，也不是新的植物学发现。

本次一位用户的两个成员身份不是两位真人或双账号联调。Iris 没有触发 NEEDS_INPUT；需要看接续证据时切换到 1CRN。所有阶段均来自实际保存的快照；首阶段展示冻结源文件的后续状态，不声称记录了上传瞬间。

## 怎样核对

右侧协议可下载原始 CSV；任务抽屉保留每次执行与对应评审；文件交接抽屉展示实际文件指纹。记录中的“远端运行原始查询记录”列出四次真实 Biology 运行，最终证据独立检查 79/79 通过。保留原始模型文字，不把每句话都当成事实：首次退回里的“其余 749 个数值”应为 599 个数值和 150 个标签，逐格核验与退回结论正确。

要参加真实协作，点顶部“邀请成员”查看队友自己的接入步骤。回放里不能输入密钥或启动连接器；解压接入包后双击 open-research.cmd，使用队长邀请进入自己的本机工作区。没有邀请时请向队长索取，不要把本演示地址当作加入链接。
