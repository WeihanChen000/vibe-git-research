# 从原界面完成 Iris 科研协作实验

后续真实账号验证已完成，见 [真实 Iris 验证结果](SCIENCEPAL-IRIS-LIVE-RESULT.md)。本文保留先前模拟调度的测试记录，二者不可混称。

此实验复用本仓库已有的 UCI Iris 数据、IRIS_CASE 提案与 IRIS_RESULT_SCHEMAS 格式，没有新增依赖或复制外部项目代码。数据来源记录见 fixtures/iris/README.md。目标是检查真实数据的来源、单位与描述性统计，演练各成员拥有自己的 Agent 时的责任和文件流转，不是新的植物学发现。

## 队友按界面操作

1. 双方用自己的本机入口加入同一房间，绑定 Codex 或自己的 SciencePAL Agent。
2. 在“我的提案 → 从公开实验填写本人提案”，一人填入 Iris 数据核验提案，另一人填入 Iris 统计复核提案；各自检查并保存。已有未保存草稿时不会直接覆盖。
3. 队长打开左上角原项目菜单，选择两人的提案，点“使用 Iris 公开数据复核模板”。标题、CSV、来源和固定成果格式一起载入；不会替对方保存提案。
4. 检查 4551 字节与 SHA256 `0fed2a99db77ec533a62dc66894d3ec6df3b58b6a8f3cf4a6b47e4086b7f97dc`，点“冻结提案并建立项目”。也可选择自己的科研文件并补充来源；更换文件后重新核对提案与验收格式。
5. 从“现在轮到谁”启动协议对齐，核对 data_audit → species_summary 的依赖与交叉评审，再发布。
6. Codex 成员准备本人任务包，在自己 Codex 中处理并交回；SciencePAL 成员在自己的算力网启动连接器。绑定平台与文件均按创建时的版本冻结。
7. 评审退回时，队长查看修改项并安排返工；下游保持阻断。等待输入时在本人 SciencePAL 原线程回答，再由原连接器接回，不另建线程。
8. 两项任务均获批后检查交接回执、最终统计与来源。可在协议抽屉下载冻结源文件，在任务或记录抽屉下载各版结果。

## 本次实际演练

从两个空白本机面板开始，通过浏览器完成加入、绑定、各自保存提案、选成员、载入数据、建项、对齐、发布、领取与交回。没有预建实验项目，没有用 create/prepare CLI 代替图形建项。

数据来自真实 150 条 Iris CSV，三个物种各 50 条。Agent 调度为显式模拟，不调用真实 SciencePAL / Codex 模型，不代表双账号已验收。Codex 侧用独立 Python csv/statistics 计算；模拟 SciencePAL 侧用 JS 重读实际 CSV、逐行评审并计算统计量。每轮都检查冻结输入哈希，最后的 Python 复核不执行对方代码。

为验证评审门禁，首轮仅将结果中的首条萼片长度从 5.1 改成 6.1，并在 limitations 明示受控错误；源 CSV 不变。这种数值仍符合 JSON 格式，所以需要独立科学评审才能发现。实际被退回，修正为 5.1 后复审通过，下游才开始。还走过一次 NEEDS_INPUT、停止连接器、原线程答复、重启接回；没有重复发布任务。

最终花瓣长度均值：setosa 1.462 cm，versicolor 4.260 cm，virginica 5.552 cm。后两种的范围分别为 3.0–5.1 与 4.5–6.9 cm，有重叠；不能仅凭均值声称完美分类或因果关系。

## 本轮发现并修正

- 原上传组件未接入团队建项；现在复用现有 source/resultSchemas 接口，保留队长权限和各自提案权限。
- 旧浅色上传底板不符合原拓扑：改为继承原深色弹层。
- 更换文件失败可能留下旧数据 / 格式：先清空旧选择，失败时禁止建项；删除后迟到的异步读取不会恢复旧文件。
- 读取尚未结束、来源不全或 URL 带凭据时禁止建项。
- 最终完成页仍留着早先“安排返工”的成功提示：完成后隐藏过期操作提示，避免误读为当前待办。
- PDB 原扩展名不被支持：客户端和服务端同步允许，原字节不变。
- 建项草稿切换弹层会保留；刷新 / 离开有未保存提醒；创建后协议抽屉显示源文件大小与哈希。

34 项全流程浏览器检查与 150 项科研回归通过。详细结果保存在开发目录 data/iris-ui-experiment/qa-report.json、project.json、scientific-result.json 与截图。接入包仅包含公开数据与可复现脚本，不包含本次私有身份和领取日志。

## 开发者重跑模拟（队友正常接入不需要）

先 npm ci / npm run build，再运行 `node apps/host/scripts/preview-iris-experiment.mjs`。模拟账号只使用 DEMO-KEY，禁止输入真实 Key。另一个终端运行 `node apps/web/scripts/verify-iris-experiment.mjs`；需 Windows Chrome 与 Python 3，可用 VIBE_GIT_PYTHON 指定 Python 可执行文件。验收脚本从本人的真实任务包读取文件，使用 fixtures/iris/calculate-experiment.py 独立计算。
