## 验收口径

1. 队长与队友是两个原 Vibe-Git 成员；提案分别由本人提交，队长不能代改队友提案。
2. 非队长不能发布；成员只能领取与回传本人任务，不能因为相同内置专家 ID 获得别人的权限。
3. structure 与 analysis 分属不同成员；每个成果由另一成员的连接器派发评审。不同连接器不等于不同账号，须结合两位本人确认及各自 SciencePAL 运行记录。
4. Host 先校验所有原始附件回执，再进行独立评审；上游批准后才派发下游。同名 JSON 重写不是原字节交接。
5. 六个 CYS 采用整残基面积；总 SASA 与独立基线差 <=3%，各 CYS 差 <=max(3 Å²,5% 基线)；不把 SG 原子面积替代整残基。
6. `evidence` 中 allApproved=true、handoffs 每项 passed=true，只证明已提交证据符合流程约束；不是平台签名、科研结论绝对正确或跨账号所有权的证明。
7. 若真实科学问题导致 request_changes，队长 rework 后保留旧成果再复评。若一轮即通过，如实记录，不为了展示而伪造退回。R2 单独记录，不把 R1 通过当作 R2 通过。
