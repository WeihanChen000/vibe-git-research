## 当前实现

`npm --silent run sciencepal:call -- <command>` 提供列出 Agent、提交、查询、采集、反馈返工和未知提交恢复。Codex 可直接调用，Key 保存在项目外。返工继续原线程，启动另一个真实 run；结果分轮冻结，防重复提交和覆盖。新增功能沿用现有客户端和 workspace.db，没有增加依赖。

这版是操作者的本地执行入口。团队成员连接器与提案权限继续保留，但本地桥接任务不会自动转成团队批准的项目。DSH 自动执行、第二真实账号和平台无关 Agent 绑定仍待接入。

## 评审脚本本身也要被评审

首轮评审计算和退回理由正确，但返回脚本将 verdict 固定写成 REJECT，而非根据错误列表计算。它是这次运行的记录，不能直接当成通用验收器。因此复评增加要求：由真实检查计算结论、覆盖所有残基对、拒绝缺失/重复/额外项目、非有限值、错误单位和来源哈希，并允许指定隔离目录供本地重放。

实际复评返回 APPROVE，三对数值与独立基线一致。但第一版复评脚本的本地隔离重放只通过 7/10，错误批准了重复残基对、额外残基对和错误 chain。将这三项真实失败反馈给原评审线程后，它返回新版 `review-r2.py`；对相同的 10 个用例重放达到 10/10（正确输入通过，其余九种错误退回）。原始文件及第一版脚本均未修改。

最后重新验证完整链条，59/59 通过：真实 Agent/线程关联、返工使用原线程且运行 ID 改变、冻结字节、输入交接哈希、执行回执、原始候选脚本保留，以及三个阶段的独立数值比对。证据包包含 12 个真实执行/评审产物、任务与运行清单、两轮评审器重放记录；另有 [工具探测结果](fixtures/structure-case/evidence/capability.json)，哈希 `6f803273477a082d19cc971a49a7b7b1803e402fed81567e32306462aca6b38c`。

边界：10 项重放是有限范围测试，不是通用 PDB 验证器认证。返回脚本仍针对 1CRN 的固定范围，不能泛化至多模型、多链、插入码或任意畸形 JSON。数据源和研究范围改变时，必须重新制定和验证协议。

## 科研价值判断与下一步决策

**已观察到的贡献：** SciencePAL 在独立沙箱实际执行科学计算，发现足以改变数值解释的单位错误，给出能执行的修正建议，并保留了原线程研究上下文。Vibe-Git 把这些工作接回 Codex，保留执行归属、字节交接、评审及修订历史。

**未证实的优势：** 本次工具探测任务使用的自定义 Agent 沙箱具备 NumPy/SciPy，未找到 BioPython、MDAnalysis、PyMOL、RDKit 或 ChimeraX 等专用工具。这不是对另一个 Agent 或平台所有领域环境的排查。本地 Codex 环境也能完成独立复算；此例不能支持“SciencePAL 不可替代”或“全面优于 Codex”。两个 Agent 也不意味着模型或账号独立。

**决策：** 保留这条闭环作为可靠演示底座；优先获得一个确实可调用、带领域技能/工具的 SciencePAL 专家 Agent，再做相同输入与公平工具条件下的对照。选择队友能人工判断的研究任务，测量正确率、误报、环境准备和人工交接步骤。若专家能力仍无法通过 API 使用，就据实主打多成员研究资产与可复核交接，不把通用计算改名为独占科研能力。接入第二成员时沿用现有成员连接器，最后再扩展 DSH。

工程验证：89 项 SciencePAL 专项测试通过；完整构建和类型检查通过。Web 包仍有约 720 kB 的已有分块体积提示，不影响本次 CLI 验证。
