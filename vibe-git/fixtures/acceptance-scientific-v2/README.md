## 怎么使用

在**新项目**创建请求的 `scientificChecks` 字段传入本 JSON；任务键必须为 `sasa`，产物字段须包含 `atom_count`、`residue_count`、`total_A2` 和 `residues[{residue_id,area_A2}]`。若新项目采用其他字段或研究对象，需要重新定义有依据的配置，不能套用本参考。

新验收的首份正式计算应满足冻结的方法、参数和 5000 点要求；提问、断线恢复、日志补证分别作为生命周期检查记录。不要把本文件直接替换进旧 `acceptance-isolated-live.mjs` 的预设 100 点试算流程：旧流程设计为先让试算进入文字退回，而更强硬检查可能更早阻断它。保留旧脚本及其证据，下一次真实验收应使用新项目与明确的新协议。
