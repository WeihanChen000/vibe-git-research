# 原拓扑里的真实科研案例回放

本演示直接复用 Vibe-Git 的顶部入口、人员拓扑、项目甘特、成员卡、文件边与右侧详情。展示 2026-10-30 已完成的 Codex × SciencePAL Biology 案例，**不启动模型、不读取当前账号、不发送实时项目操作**。

## 打开

解压队友源码包后，安装 Node.js 24+，双击 **open-replay.cmd**。首次准备依赖和构建需要网络；构建完成后的回放只访问本机静态文件，不需要 SciencePAL Key 或第二账号。

已构建的目录中也可运行：

```powershell
npm run research:replay
```

打开终端打印的地址并保留终端。它绑定随机本机端口，不能直接发给另一台电脑；队友用同一个源码包在自己电脑启动。不要通过 file:// 直接双击 index.html。

已有科研工作区中，点击顶部下方 **回放真实科研案例** 即可进入同一回放。在回放顶部的“本地工作区”位置可以返回当前工作区；独立演示入口没有当前账号工作区，因此不提供这个返回操作。

## 一分钟讲清楚，再按需展开

顶部沿用原控制条，增加“回放案例”选择；演示启动默认 1CRN 的完成阶段，也可切到 Iris；这不改变真实项目的通用建项入口。每个案例保留上一阶段、自动播放 / 暂停、下一阶段和阶段选择。自动播放每九秒前进，最后停在完成状态；点击节点或详情入口会暂停，方便讲证据。原有“只看文件交接”、人员拓扑 / 项目甘特、协议 / 待办 / 记录和详情收起方式保持不变。

### Iris：两次退回、返工与交接

九个阶段全部来自真实保存快照：源文件冻结 → 数值错误退回 → Codex 修复待复审 → 获批等待交接 → 实际收到文件 → 缺少可复现代码再次退回 → Biology 补代码 → Codex 复审 → 完成。两次退回原因不同，不能混为同一错误；详情见 [Iris 案例说明](SCIENCEPAL-IRIS-REPLAY-BRIEF.md)。

21 个附件逐一校验 SHA256；本案例没有触发 NEEDS_INPUT。第一次数值错误是明示受控注入，第二次缺代码是真实远端产物缺陷。Iris 的验证记录为 79/79。

### 1CRN：等待输入与原线程接续

| 阶段 | 建议讲述与操作 |
| --- | --- |
| 1. 单位错误被退回 | 查看原评审：真实坐标算出约 2 Å，首版故意写为十分之一。点文件边，确认下游被阻断 |
| 2. 返工后的格式失败 | 原“记录”保留 INVALID 评审。数值正确不意味着可以绕过完整证据要求 |
| 3. 修正版复审通过 | 文件被批准放行，但还未收到下游实际字节回执；这里不会提前亮起“已交接” |
| 4. 等待输入 | 原“现在轮到谁”显示 SciencePAL 成员，任务卡也显示等待回答，保留原线程 ID |
| 5. 同线程接续 | 在原记录里展开“原线程接续”，查看同一 Thread 与不同的前后 Run；下方可核对远端 asked / completed 查询记录 |
| 6. 实际文件交接 | 文件边三项检查全部通过；可下载当时收到的获批文件，核对 SHA256 |
| 7. 科学复核完成 | 两项任务均通过另一端评审；Biology 总面积与 Codex 独立 NumPy 基线相差约 0.101% |

案例写在 URL 的 case 参数中，当前阶段写在 step 参数中，刷新或浏览器返回可恢复。每个阶段显示真实记录时刻；成员显示“历史成员”，不伪装当前在线。桌面沿用右侧抽屉，手机沿用原版详情覆盖方式，收起详情后可继续选阶段。

顶部 **邀请成员** 在回放中打开“队友用自己账号接入”说明；算力网入口显示当时的执行平台，不显示 Key 输入或启动按钮。真实成员仍通过原本机工作区接入，步骤见 [队友接入](SCIENCEPAL-TEAM-START.md)。

## 哪些是真实记录，哪些是展示重建

Iris 九个阶段均为原始快照，无阶段重建。1CRN 六个阶段直接来自保存的项目快照。接续瞬间使用 NEEDS_INPUT 快照和真实续接回执重建，并明确标“依据真实续接回执重建”；不会把未来产物或最终评审提前放进该阶段。

原始研究附件与产物按冻结文件 ID 保存，逐一核对大小与 SHA256，字节不修改。失败和无效评审保留。回放使用同一张图的状态解释规则：只有下游已校验的输入回执匹配获批文件 ID，才显示交接完成。

单账号、两个工作流身份；首轮单位错误和探针参数确认是明示的受控测试。真实数据、远端模型执行和独立重算均已完成，但不能据此宣称第二位队友已经用另一账号接入，或 SciencePAL 模型智力优于 Codex。

完整研究报告位于开发目录 `SCIENCEPAL-MIXED-LIVE.md`。队友包内的精选记录在 `apps/web/public/research-replay/1crn/`：case.json 为阶段说明与快照，manifest.json 为文件指纹，files/ 为原始附件，remote-observations.json 为续接查询记录。它不包含 API Key、邀请凭据、成员 token、数据库或私有连接器日志。

## 开发复核

```powershell
# 从本机保存的真实证据重新生成，只适用于持有该次完整证据的开发目录
node apps/host/scripts/export-research-replay.mjs
node apps/host/scripts/export-iris-replay.mjs
npm run build
npm run research:replay
# 另一个终端：真实浏览器交互、零 API 调用、原始字节与移动宽度
node apps/web/scripts/verify-research-replay.mjs
```

队友不用重新导出，也不用重新运行科研实验即可看回放。export 脚本只读取本次已通过核验的本地证据，不使用 SciencePAL；新的真实联调按成员指南创建自己的项目。

## 1CRN 首版验收（历史记录）

149 项科研回归、33 项回放浏览器检查和 19 项原可操作混合流程浏览器回归通过。回放浏览器未请求实时 API、未写入项目或调用外部模型；原操作流程的 19 项回归使用独立合成环境，不混作真实科研证据。17 个原始附件逐一核对大小与 SHA256，分享元数据去掉领取幂等标识。手机收起详情、长接入说明、浏览器返回和刷新恢复阶段均已检查。


## 首次观看的入口

回放上方按当前案例说明 Iris 或 1CRN 的问题与双方分工。点“案例与证据说明”会在原顶部弹层中解释平台各自负责什么、科研工具的实际证据、结果数值与验证边界。点击节点、打开顶部说明、切换人员拓扑 / 甘特，或离开浏览器标签页都会暂停播放，阅读后由观看者决定继续。

原个人菜单提供“队友接入说明”；队友不需要队长权限。说明区的行内命令沿用正常文字排版，长命令块可滚动。Codex 算力面板优先连接已有任务包界面，CLI 保留为折叠选项。
